# EtTu 2.0.3911 한국어 이행

원본은 [공식 EtTu 2.0.3911](https://github.com/rotators/Fo1in2/releases/tag/v2.0.3911)이다. 릴리스 ZIP의 SHA256은 `e94873abd8e0510f1dd4ae17e73117e9cb099e7700595273acc007e1184c50e7`이며 GitHub가 공개한 digest와 일치했다.

## 번역 보존

이전 기준 1.16.3771과 새 기준의 공개 영어 MSG를 ID 및 중복 ID의 출현 순서로 비교했다. 변경된 영어 레코드 9개를 검토해 한국어는 신규 4개와 기존 2개만 반영했다. 나머지 3개는 기존 번역이 새 원문 뜻과 같아 유지했다.

| 파일 | ID | 처리 |
| --- | --- | --- |
| GENCHAT | 194, 195, 196 | 새 저지능 대화 문구 번역 |
| GENCHAT | 211 | 도둑질 불가 안내 추가 |
| IRWIN | 2000 | 삭제된 쿠퍼 농장 이름·괄호 설명을 제거하고 새 길 안내 반영 |
| IRWIN | 2002 | 기존 한국어가 새 원문 뜻과 같아 유지 |
| SETH | 2100 | 영어 문장 다듬기이며 기존 한국어 유지 |
| SLAPPY | 2200 | 영어 문장 다듬기이며 기존 한국어 유지 |
| WORLDMAP | 2998 | 원본에서 지운 비활성화 안내를 빈 문자열로 맞춤 |

화면 확인에서 기존 한국어 MISC.msg의 메뉴 이름 여섯 개가 영어로 남아 있음을 발견해 ID 9–14를 한국어로 보완했다. 번역 데이터 파일은 GENCHAT.msg·IRWIN.msg·WORLDMAP.msg·MISC.msg 네 개만 변경했다. 다른 번역 파일은 바이트 단위로 같고, 변경 파일의 나머지 한국어 MSG 레코드와 음성 필드도 보존했음을 자동 비교했다. [변경 레코드 및 파일 해시](ETTU_2_0_TEXT_MIGRATION.json)를 함께 기록한다.

기존 UTF-8 자막은 소스에서 유지하고 클래식 ZIP을 만들 때 CP949로 엄격 변환한다. SVE 원문 백업은 배포 ZIP에서 제외한다.

## 원본 게임과 출력 모듈

2.0의 스크립트·설정·리소스를 사용한다. 이전 1.16 설치본의 수정된 게임 파일을 재사용하지 않는다. 공식 추출 도구와 사용자가 보유한 Fallout 1 MASTER.DAT로 필요한 원본 자산을 가져온다.

공식 릴리스에 포함된 `ddraw.dll`은 우리가 검증한 공식 sfall 4.5.1과 SHA256이 같다. 이 DLL과 2.0의 `sfall.dat`는 그대로 유지하고 공통 출력 엔진의 `ettu` 프로필을 사용한다. 글꼴 설정은 본문 Galmuri9 / 10 / 400, 버튼 Galmuri11 / 14 / 600이다.

이 작업은 클래식 `Fallout2.exe` 실행 경로를 대상으로 한다. 동봉된 `fallout2-ce.exe`의 한국어 출력 검증과 장시간 플레이는 별도다.

## 검증 상태

공식 ZIP에서 만든 1024×768 독립 시험본을 공통 설치 도구의 `ettu` 프로필로 구성했다. 필요한 Fallout 1 자산은 공식 추출 도구와 사용자 보유 MASTER.DAT에서 가져왔다.

- 사용자: 첫 실행의 확인한 본문·줄바꿈 정상. 메뉴의 기존 영어 항목 여섯 개를 보완한 뒤 재실행에서 한국어 메뉴와 배치 정상, 종료 확인.
- 런타임: CP949 줄바꿈·CJK 판정·글꼴 어댑터의 로드를 메모리에서 확인.
- 원본 보존: EXE와 필요한 설정 파일 네 개를 제외한 공식 배포 파일 10,830개가 시험본에서도 원본과 일치했다. 공식 sfall DLL·sfall.dat·2.0의 모드 설정과 스크립트는 유지했다.
- 설치·복구: 실제 2.0 설정을 사용한 임시 폴더 검사에서 언어 외 Fallout2.cfg 전체 키, fo1_settings.ini 및 공식 sfall 보존과 원본 복구 통과.

추가한/수정한 문구가 등장하는 모든 퀘스트 분기나 장시간 플레이까지 직접 확인한 것은 아니다.
